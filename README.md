## 🚀 Step-by-Step Onboarding & Validation Guide

Follow these SRE steps to deploy, validate, and monitor the Local Cloud Dev sandbox:

#### 1. Prerequisites
- [x] Docker Desktop or Docker Engine installed
- [x] Docker Compose v2.0+
- [x] AWS CLI / LocalStack wrapper (awslocal) installed (optional)

#### 2. Local Setup
```bash
git clone https://github.com/Pradeeptalari14/tp-local-cloud-dev.git
cd tp-local-cloud-dev
```

#### 3. Start Sandbox Environment
Launch the Docker Compose services in the background:
```bash
docker compose -f primary_config/docker-compose.yml up -d
```

#### 4. Validate Environment Setup
Check that services are healthy and running on custom ports:
```bash
bash scripts/validate.sh
```
